Clipper Backend API Docs

Base URL: http://localhost:3000/api (default)
Versi: 1.0 | Terakhir diperbarui: 2026-02-06

Flowmap (Ringkas)

Frontend Renderer → Fastify API → Queue/Workers → File System & DB Frontend Renderer → Fastify API → Static /downloads & /processed

Health & Static

GET /processed/*
File statis untuk download & hasil proses

Video & Editor

POST /video/download
{
  "url": "https://www.youtube.com/watch?v=...",
  "projectId": "optional",
  "downloadSubtitles": true
}
{
  "status": "queued",
  "jobId": "uuid",
  "message": "Download started"
}
POST /video/download/:id/cancel
POST /video/download/:id/retry
POST /video/upload
{
  "filePath": "C:\\path\\to\\file.mp4",
  "platform": "tiktok|instagram|youtube",
  "metadata": { "title": "..." },
  "projectId": "optional"
}
POST /video/upload-file
multipart/form-data, field file
POST /video/analyze
{
  "id": "videoId",
  "modelSize": "tiny|base|small",
  "method": "youtube|whisper|auto"
}
POST /editor/clip
{
  "id": "videoId",
  "startTime": 10,
  "duration": 15,
  "clipId": "optional"
}
POST /editor/merge
{
  "filePaths": ["C:\\...\\a.mp4", "C:\\...\\b.mp4"],
  "projectId": "projectId",
  "outputName": "final.mp4"
}
POST /editor/clips/batch
{
  "videoId": "videoId",
  "clips": [
    { "title": "Highlight", "start_time": 10, "end_time": 20 }
  ]
}
DELETE /editor/clips/:id
POST /editor/clips/:id/unprocess

queueName: download | analyze | process | upload | auto | render
